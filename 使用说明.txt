============================================================
  TouchShow 打包版使用说明
============================================================

TouchShow 3D 展览展示系统（打包免安装版），适用于触摸屏一体
机 / 展厅大屏：全屏展示飞机 3D 模型与产品 CoverFlow 卡片。


一、目录结构
------------------------------------------------------------

打包完成后，exe 所在目录结构如下：

  TouchShow.exe                主程序（双击运行）
  TouchShow-server.exe-xxx.exe 服务端 sidecar（Tauri 版才有，须与 exe 同目录）
  使用说明.txt                  本说明文档（删除不影响程序运行）
  public/                      运行时资源，可随时修改 / 更换
    ├─ config.json             展示配置（类别 + 产品）
    ├─ Models/                 3D 模型（*.glb / *.fbx，文件名由 config.json 指定）
    └─ products/               各分类产品图片


二、运行
------------------------------------------------------------
1. 双击 TouchShow.exe 即可运行。
2. 自动进入全屏展厅（独立 EXE 用系统浏览器全屏打开，Tauri 版弹出应用窗口）。
3. 启动时会显示资源加载进度，并检测本机局域网地址。
4. 资源加载完成后点击「进入展厅」，加载页面会向右移出后进入主界面。
5. 关闭窗口 / 结束进程即退出，再次双击重新运行。
6. 首次运行若杀毒软件提示，请选择"允许"（Tauri 版因有签名误报更少）。


三、展示屏操作
------------------------------------------------------------

图片模式：

1. 点击右侧一级分类展开 / 收起该分类的产品列表。
2. 点击二级产品菜单可定位到对应产品，并播放 CoverFlow 翻页动画。
3. CoverFlow 支持鼠标拖拽、触摸滑动、横向滚轮和点击两侧卡片切换。
4. 同一分类包含 2 个或以上产品时支持无限循环切换。
5. 页面空闲一段时间后会自动翻页，进行手动操作即可退出自动翻页。

3D 模型模式：

1. 中央展示 3D 模型，支持鼠标拖拽旋转，滚轮 / 双指缩放与平移。
2. 点击右侧产品后，模型自动聚焦到对应部件并高亮，同时显示产品信息框。
3. 点击分类（未选产品）仅切换分类说明，不聚焦具体部件。


四、修改展示内容（无需重新打包）
------------------------------------------------------------

所有展示内容都在 public/ 目录，修改后刷新屏幕即可生效，
无需重新打包：

1. 产品图片：放在 public/products/<目录名称>/<产品>.png（<目录名称>为分类的 dir 字段，未设置时为分类名称）。
2. 3D 模型：替换 public/Models/<模型名>.glb（文件名在管理页 / config.json 的 model 字段指定）。
3. 展示配置：编辑 public/config.json，可增删类别 / 产品、修改标题与说明。
4. 展示模式（图片 / 模型）、模型文件与串口联动：在远程配置页「设置」中直接修改，保存后屏幕实时刷新。

浏览器直接上传（推荐，无需碰文件系统）：

1. 打开远程配置页 http://<服务器IP>:3000/admin，进入「资源上传」标签页。
2. 产品图片：选择分类（上传到其目录名称 public/products/<目录名称>/ 下，目录自动创建）、
   可选目标产品，再选择图片文件（png / jpg / webp / gif / svg）点「上传图片」；
   若选了目标产品，上传成功后会自动把该产品的图片字段改为新图并保存推送。
   目录名称在「分类与产品」页设置（dir 字段，缺省用分类名称）。
3. 产品图片也可在「分类与产品」页每个产品的「图片路径」下方，直接从分类目录快选。
4. 3D 模型：选择 .glb / .fbx / .gltf 文件点「上传模型」，随后到「设置」页选择该模型
   并保存，所有展示屏自动切换加载。
5. 同名文件直接覆盖；需要管理令牌时请先在页面顶栏填写。


config.json 结构
------------------------------------------------------------

{
  "model": "C919.glb",    // 可选：3D 模型文件名（public/Models/ 下，缺省 C919.glb）
  "displayMode": "image", // 可选：展示模式 image 图片模式（CoverFlow 轮播，缺省）/ model 3D 模型模式（隐藏 CoverFlow 仅展示模型）
  "serial": {              // 可选：串口联动设置（不配置 = 关闭）
    "enabled": false,      // true = 切换产品时把 action 发送到串口
    "port": "COM3",
    "baudRate": 9600,
    "dataBits": 8,
    "stopBits": 1,
    "parity": "none",
    "template": "{action}\r\n"  // 发送格式模板，{action} 会替换为产品 action 值
  },
  "category": [
    {
      "label": "防火系统系列产品",        // 侧边栏类别名
      "dir": "fire-system",              // 可选：产品图片目录名（public/products/<dir>/，缺省用 label；分类名含特殊字符时建议设置）
      "icon": "/icons/category-fire.svg", // 类别图标（图片路径或 emoji）
      "description": "类别说明……",
      "product": [
        {
          "label": "防火系统控制器",   // 产品标题
          "action": "fire_control",   // 产品标识（串口模板 {action} 用它替换）
          "description": "产品描述",
          "image": "/products/防火系统/防火系统控制器.png",
          "object": "模型物体名",     // 可选：3D 模式下聚焦并高亮的模型物体
          "rotate": 0                 // 可选：聚焦前模型绕 Y 轴旋转角度（度）
        }
      ]
    }
  ]
}


远程配置页面（可选）
------------------------------------------------------------

程序运行时，同一局域网内任意设备可访问配置管理页：

  http://<电脑IP>:3000/admin

管理页含「分类与产品 / JSON 模式 / 设置 / 远程控制 / 客户端」
五个标签：

- 修改并保存配置后，所有展示屏会实时刷新（WebSocket），无需手动操作。
- 「远程控制」可即时切换分类 / 产品 / 侧边栏，不写入配置文件；
  支持广播全部屏，也可在页顶「目标屏幕」选单台屏定向控制。
- 「客户端」页实时列出在线屏及各自当前展示内容；展示屏可用 URL
  命名便于区分：http://<电脑IP>:3000/?name=屏A
- 保存配置 / 远程控制 / 串口管理均需管理令牌：在管理页令牌框填写后
  保存在本机浏览器并自动携带。运行前可用环境变量 ADMIN_TOKEN 自定义
  令牌（如 123456）；未设置时使用默认令牌 11223344。


五、常见问题
------------------------------------------------------------

  问题                          解决
  --------------------------------------------------------
  双击 exe 后浏览器未自动打开    手动访问 http://127.0.0.1:3000/；或检查系统默认浏览器
  端口 3000 被占用               运行前设置环境变量 PORT=3001 更换端口
  更换图片/配置后没变化          确认文件在 public/ 目录内、文件名大小写一致，并刷新页面
  杀毒软件误报                   添加信任，或改用 Tauri 版
  重新打包提示 EPERM             先关闭正在运行的 TouchShow 进程再打包
  远程打不开 admin 页            检查电脑与设备是否同一局域网、防火墙是否放行 3000 端口


六、环境变量（可选）
------------------------------------------------------------

  PORT               服务端口（默认 3000）
  ADMIN_TOKEN        配置管理令牌（不设置 = 使用默认 11223344）
  TOUCHSHOW_NO_OPEN  设为 1 时不自动打开外部浏览器
